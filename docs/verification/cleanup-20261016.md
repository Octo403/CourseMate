## “个人资料”首屏问题

原 ECS 包中的源码与当时工作区逐文件一致。原 `app.js` 在其他延后加载脚本完成前启动首次请求，可能先调用未被 `study.js` 扩展的渲染函数，保留“个人资料”首屏。

使用原 ZIP 的 `app.js` 已在 DOM fixture 中复现启动顺序失败。修复后等待 `DOMContentLoaded` 再初始化，初始 HTML 直接显示学习入口；云端首次设置使用访客自己的模型 API，刷新页面状态不会重新启用服务器 ChatGPT 登录。

安装器重新执行时先停止原任务及相关进程；停止脚本按当前部署的准确命令路径匹配，也覆盖虚拟环境启动的基础 Python 子进程，并保留其他部署进程。
