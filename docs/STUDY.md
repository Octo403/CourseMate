# 课程学习与个人题库

2026-10-12 起，源码界面默认使用 `study` 模式。保留课程收集与整理，将原“个人资料”主入口改为“我的学习”。不加载微信同步、个人资料检索和本机聊天/向量模型。当前工作区的旧课程、微信及运行数据已按要求清理，首次使用需要重新导入资料。

## 使用流程

1. 默认使用当前 Windows 账户已登录的 Codex CLI / ChatGPT，网页“设置”可刷新型号并保存；也可切换到兼容模型 API，填写自己的地址、Key 和型号。
2. 在“课程资料”收集公开课程，或上传文件、添加公开网址。资料处理仍在后台进行。
3. 在聊天框通过 `@ 题库` 选择课程，描述知识点、年份、题型等要求。系统先用普通字符检索缩小候选，再交给 ChatGPT 核对；不会下载或加载向量模型。
4. 在纸上或其他地方完成题目，再点击题目卡片的状态按钮。标记立即保存，同一道题在其他会话也显示相同状态。
5. 需要核对时点击“解答与方法”，或输入“解答第一题并进行方法归纳”。默认复用已存解答，“重新求解”重新调用所选模型并替换当前解答。
6. 打开“我的学习”，查看已标记或已生成解答的题目、知识点和方法。课程聊天上方的“下次找题”控制之后的检索范围；也可直接说“找做错的题”。

输入框的“＋ 图片 / 文件找相似题”支持图片、PDF、Word、TXT 和 MD，也可粘贴图片或拖入文件。先通过 `@ 题库` 选择课程，再发送附件与找题要求。每次 1—3 个文件、合计 20 MiB、最多 6 页/张，作为同一道完整参考题；多题文件需说明题号。Word 在本机转换，需要 Word 或 LibreOffice，也可另存 PDF。当前附件交给所选在线模型识别后，与本地题库候选比较；不会自动导入课程题库，不会用于之后其他轮次。上传原件及识别结果在本机保留，可在会话中展开核对。

处理时显示读取、识别、检索、核对等简短阶段进度；完成后自动隐藏进度，只保留最终结果与题卡。匹配理由和候选覆盖范围放在默认收起的“匹配说明 / 检索说明”中，来源缺口仍标在题卡上。学习页面不展示开发调试 JSON 或初稿。

## 主 Agent 与学习知识库

无需选择课程即可聊天、解释知识或计算。选中课程仅限定找题范围，普通问候和知识解释仍由主 Agent 处理。在线连接参与 LangGraph 的结构化意图解析、草稿生成与第二阶段自省；模型格式或调用失败保留错误提示，并允许后续轮次继续。

在“设置 → 知识资料”导入 TXT / MD。资料切片后保存在独立学习库，本机字符 TF-IDF 向量化并建立持久化 FAISS 索引；先取 Top-N 候选，再由所选在线模型逐片段打 0—1 相关性分数，过滤低分、重复片段后生成与自省。这里使用的是 TF-IDF 向量粗检和 LLM Rerank，不宣称使用 BGE 神经向量或本地交叉编码器。没有相关资料时明确提示，并允许基于通用知识回答；个人经历无证据时仍不编造。

知识资料与会话位于 `data/runtime/ui-study/learning.sqlite3`，FAISS 位于同目录的 `learning-retrieval/`；便携构建位于 `user-data/application/`。导入文档原文保存在本机，当前问题、必要历史及候选片段会交给在线模型。只导入允许发送的学习资料；学习模式不打开旧微信或个人检索库。一般生成轮次调用意图、草稿与自省，知识命中时另调用 Rerank；原题检索仍直接展示原题，避免模型改写题设。

## 做题状态

| 状态 | 含义 |
| --- | --- |
| 未做过 | 默认状态，也可以手动改回 |
| 做过 | 已尝试，尚未判断对错 |
| 做对 | 用户确认本次完成正确 |
| 做错 | 用户确认本次完成错误 |

四种状态互斥；筛选“做过”时包含做对和做错。打开题目、查看来源答案、生成或查看 ChatGPT 解答都不会自动更改状态。目前没有逐次作答历史、自动判分、自定义标签。

## 解答与方法

书面参考解答要求覆盖全部小问，保留题设条件、变量定义、必要分类、推导或证明及最终结论。题目图像可用时与原图一起交给 ChatGPT；已有配对来源答案作为参考材料。模型生成内容单独标注，不当作官方答案。

每道题只归纳一个主要方法点，用一两句话概括可复用的关键思路；识别线索、通用步骤、适用条件和易错点折叠在其下。旧解答保留，界面只显示首个方法；点击“合并方法并重新求解”可按新要求重新归纳。

图论、几何、集合关系等适合图解的问题，模型可附一到两张可缩放示意图；不需要图的解答不强行配图。图使用受类型约束的点、线、箭头和圆，浏览器在本机绘制 SVG，不执行模型生成的 HTML、SVG 或脚本。题设示意与方法示例明确区分，不能凭图补造条件；图形结构与文字推导仍需核对。公式使用本地 KaTeX 输出 MathML，不请求外部字体或脚本；不支持的公式保留 LaTeX 原文。

题设缺失或图像无法辨认时，模型应返回具体需要补充的内容。未提供必要原图、完整题图超出调用范围时，应用直接提示补充。网络、认证或额度失败不会保存伪造解答。Schema 校验只检查输出结构，不能证明数学正确性。

## 数据位置与更新

| 内容 | 源码默认路径 | 便携构建路径 |
| --- | --- | --- |
| 课程题库、原件、解析 | `data/question_bank/` | `user-data/question_bank/` |
| 状态、题目快照、最新解答 | 题库目录的 `study.sqlite3` | 同左 |
| 个人题库保留的题图 | 题库目录的 `study-assets/` | 同左 |
| 学习会话与检查点 | `data/runtime/ui-study/` | `user-data/application/learning*.sqlite3` |
| 界面偏好、课程固定与筛选 | `data/runtime/ui-study/ui.sqlite3` | `user-data/application/ui.sqlite3` |
| 上传参考题原件与页面图 | 题库目录的 `processed/query-uploads/` | 同左 |

先停止服务并等待后台任务结束，再复制整个题库和界面数据目录备份。学习记录按当前用户及课程分开，已确认的同题出处共享标记。来源重新解析导致题目 ID 改变时，通过原出处、成员路径、题号和完全相同的题干重新匹配。题干改变时不自动继承旧标记；已保存的旧题、题图和解答仍保留在“我的学习”。保存的历史快照不会拿旧 ID 请求新题解答。

ChatGPT 通过当前账户已登录的 Codex CLI 调用，不复用 API Key；API 模式使用用户保存的兼容接口。主图发送当前问题、必要学习历史与相关知识片段；题库调用发送找题要求、候选或所选题目及相关图像/来源答案，不提供个人资料库。CLI 在临时目录的只读沙箱运行，禁用 shell 和联网搜索；不要求复制账户凭证。
