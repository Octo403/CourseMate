AnotherMe Windows 课程学习版

1. 将压缩包完整解压到可写目录，不要在压缩包内直接运行。
2. 在当前 Windows 账户安装 Codex CLI，执行 codex login 登录 ChatGPT。
   本程序通过 CLI 调用 ChatGPT；仅在浏览器或其他账户中登录不能自动复用。
3. 双击 Start.bat，在设置中刷新 ChatGPT 型号、选择并保存。
   无需启动本地大模型，不需要模型权重或 GPU；调用需要联网和账户可用额度。
4. 打开“课程资料”，收集公开课程，或上传 PDF / Word / MD / TXT / HTML / ZIP、添加网址。
   示例资料目录里的 MD 是原创虚构试题，可以用来体验导入。
5. 在聊天框通过 @ 题库选择课程，输入知识点、年份、题型等要求。
   程序先缩小课程候选，再由 ChatGPT 理解要求并筛题，不使用本地向量模型。
6. 完成题目后手动标记“未做过 / 做过 / 做对 / 做错”。
   “做过”表示已尝试尚未评价；筛选做过时包含做对、做错。
7. 点击“ChatGPT 解答与方法”，或输入“解答第一题并进行方法归纳”。
   结果包含书面参考解答、知识点、方法步骤、适用条件和易错点。
   查看解答不会自动更改标记；已存解答直接复用，“重新求解”重新生成。
8. “我的学习”汇集保存过的题目和逐题方法，可以按状态筛选；重启后保留。
9. 使用结束后双击 Stop.bat。备份、更新或移动数据前，等待后台任务结束。

资料与备份
- user-data\question_bank：课程题库、原件、解析；study.sqlite3 为学习状态和最新解答，study-assets 为保留题图。
- user-data\application：界面偏好，以及独立 learning.sqlite3 学习会话与检查点。
- 备份请在停止服务及后台任务结束后复制整个 user-data；更新时不要用空目录覆盖旧资料。
- 包内不附带微信、个人资料或已收集的课程库；学习模式无需本机聊天模型。
- 找题要求、候选和所选题目图文会按需发给 ChatGPT；做题标记在本机筛选。
- 选择 MinerU 在线解析时，相关资料发送至 MinerU。Token 可用当前 Windows 账户加密保存。
- 发布包不包含账户凭证、个人资料或预先收集的课程库。

文档与解答限制
- DOC / DOCX 使用包内 LibreOffice 转换；含 7-Zip 组件的构建还支持 RAR / 7z。
- 字体、公式、分页和 OCR 可能与原件不同，应核对原题图及来源。
- ChatGPT 输出为模型生成的参考解答，不等同于官方标准答案，结构校验不能保证数学正确。
- 题设缺失时保留待补充说明，不应将缺失条件下的内容当成完整解答。
- 当前方法按题积累，尚未实现跨题知识体系、自动判分或手写答案批改。

遇到问题
- 找不到 CLI：新开 Windows PowerShell，执行 where.exe codex、codex --version、codex login status。
- 将查到的完整路径填入设置的“Codex CLI 路径”，刷新型号并保存；安装后可直接重新检测。
- 认证、网络或额度失败不会生成离线假解答；检索回退时明确标示普通本地候选。
- 网页未自动打开时复制启动窗口中的 http://127.0.0.1:端口 到浏览器。
- 启动卡住时查看 user-data\startup.log；异常另有 startup-error.log。Diagnose.bat 仅检查依赖。
- 刷新公开课程失败保留已有资料；403 / 429 请按提示等待，407 请检查代理，404 检查来源。
- 面向 Windows 10/11 x64，其他平台尚未验证。

本说明供当前源码构建的学习版使用；构建后的 ZIP 需重新完成运行验收。
